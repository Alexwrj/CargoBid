# CargoBid

Frontend-приложение для работы с грузовыми аукционами. На текущем этапе
реализован только запускаемый фундамент: маршрутизация, providers, MSW и
тестовая инфраструктура.

## Требования

- Node.js 24.12.0 или совместимая актуальная LTS-версия;
- npm 11+.

Проект использует npm, потому что репозиторий изначально не содержал lock-файла,
а этот package manager был выбран пользователем. Устанавливайте зависимости
через `npm ci`, чтобы использовать версии из `package-lock.json`.

## Команды

```bash
npm ci
npm run dev
```

Дополнительные проверки:

```bash
npm run lint
npm run typecheck
npm run test:run
npm run format:check
npm run build
```

`npm test` запускает Vitest в watch-режиме, `npm run preview` — локальный
просмотр production build, а `npm run format` форматирует поддерживаемые файлы.

## Маршруты

| URL                          | Назначение                     |
| ---------------------------- | ------------------------------ |
| `/`                          | Перенаправление на `/auctions` |
| `/auctions`                  | Placeholder списка аукционов   |
| `/auctions/:auctionUuid`     | Placeholder деталей аукциона   |
| `/auctions/:auctionUuid/bet` | Placeholder установки ставки   |
| любой неизвестный URL        | Страница 404                   |

Страницы загружаются лениво. Product UI, фильтрация, история и установка ставки
будут добавлены на следующих этапах.

## Архитектура

```text
src/
  app/       composition root, providers, router, глобальные стили
  pages/     композиция экранов маршрутов
  shared/    предметно-независимые UI и технические части
  mocks/     временная HTTP-реализация API через MSW
  test/      setup и общий render helper
```

Пустые `features` и `entities` намеренно не созданы. Они появятся вместе с
реальными пользовательскими сценариями и предметными моделями.

Разрешённое направление зависимостей:

```text
app/pages → features → entities → shared
```

`shared` не импортирует верхние слои, pages не импортируют другие pages, а
прикладные слои не обращаются к mock handlers или mock data. Очевидные нарушения
alias-импортов проверяются ESLint. Alias `@/*` указывает на `src/*`.

## MSW

- В браузере worker динамически импортируется и полностью запускается до React
  render только при `import.meta.env.DEV`.
- Production bootstrap не импортирует и не запускает MSW.
- В тестах Node server запускается из `src/test/setup.ts`; необработанные запросы
  считаются ошибками, а временные handlers сбрасываются после каждого теста.
- `GET /api/v1/health` — техническая проверка инфраструктуры, а не часть
  продуктового Auction API.

`openapi.auctions.v1.json` остаётся неизменяемым источником API-контракта.
Контрактный TypeScript-слой относится к следующему этапу.
