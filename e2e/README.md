# E2E tests

Здесь должны находиться только тесты, которые запускают приложение в реальном
браузере и проверяют его через публичный пользовательский интерфейс.

E2E runner пока не подключён. Текущие проверки на Vitest, React Testing Library,
memory router и MSW относятся к `src/test/scenario`, даже если охватывают полный
пользовательский путь. После выбора browser runner его конфигурация и тесты будут
добавлены в этот каталог отдельной итерацией.
